# 🐍 Snake Water Gun Game

A simple **Snake Water Gun** game built with **Python and Tkinter**.

This project started as a command-line game and was later converted into a graphical user interface (GUI) using Tkinter.

## 🎮 How the Game Works

The rules are:

* 🐍 **Snake beats Water**
* 💧 **Water beats Gun**
* 🔫 **Gun beats Snake**
* Same choice → **Draw**

The computer randomly selects one of the three choices, and the player selects their choice using the GUI buttons.

## ✨ Features

* 🖥️ Simple graphical interface using Tkinter
* 🐍 Snake, Water, and Gun buttons
* 🤖 Random computer choice
* 🏆 Win, lose, and draw detection
* 🔄 Play multiple rounds
* 🎨 Emoji-based visual interface

## 🛠️ Technologies Used

* **Python 3**
* **Tkinter**
* **Random module**

No external Python packages are required.

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/gopalgouda/snake-water-gun.git
```

### 2. Go into the project folder

```bash
cd snake-water-gun
```

### 3. Run the game

```bash
python snake_water_gun_gui.py
```

On some systems, you may need:

```bash
python3 snake_water_gun_gui.py
```
